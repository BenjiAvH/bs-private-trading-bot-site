# BS Private Trading Bot — project website

Static informational page for Benjamin's private, non-commercial trading-bot development project. It describes intended own-account use, demo-first development and current limitations. No broker approval or investment performance is claimed.

**This repository contains only the public website.** It must never contain trading source code, `.env`, credentials, broker account identifiers, research data or personal contact details.

Publishing source: `site` branch, repository root, GitHub Pages. No custom domain, external dependencies, tracking scripts, login or form processing.

Local preview: serve this directory with a loopback-only static HTTP server. The page is responsive and works without JavaScript.
